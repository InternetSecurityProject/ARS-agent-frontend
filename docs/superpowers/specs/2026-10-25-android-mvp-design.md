# Android MVP 화면 구현 범위

사용자가 승인한 Kotlin + Compose, APK 팀 배포 계획과 확정 Figma를 구현한다.

- UI-first: 모의 데이터로 통화·연락처·키패드·상세, 일반 통화/종료, B01–B07, C01–C04, D01을 연결한다.
- 010은 일반 전화만, 그 외 유효 번호는 일반/Agent 두 경로. 이 규칙은 실제 ARS 지원 보장이 아니다.
- B01 목적과 C02 추가 답변은 입력 완료 후 자동 진행. 별도 시작/확인 버튼 없음.
- C03 민감정보는 요청 길이를 채우면 자동 처리하고 즉시 버린다. 데모에서 실제 개인정보를 입력하지 않는다.
- C04 DTMF 키는 즉시 반영. 입력값과 민감정보를 로그·SavedState·디스크에 저장하지 않는다.
- 밝은 파스텔 통화 배경, 공통 헤더, 60dp 보조/72dp 종료·취소 버튼. C03/C04는 카드 없는 키패드.
- 실제 시스템 상태 표시줄/제스처 영역을 사용한다. 피그마의 가짜 상태 표시줄은 앱에 복제하지 않는다.
- 실제 발신·마이크·연락처/통화기록 읽기·백엔드 API는 이번 작업의 범위가 아니다. 데모임을 명확하게 표시한다.
- REST/WS 어댑터가 이후 모의 상태를 대체하도록 상태 및 화면 렌더링을 분리한다.
- GitHub Actions: PR/push 검사 및 APK artifact, 수동 빌드. 배포용 서명키는 저장하지 않는다.

선택: 새 빈 리포의 feature 브랜치에서 작업한다. 초기 커밋이 없어 추가 worktree는 만들지 않는다.
SF Pro는 Apple 전용 폰트이므로 Android에서 재배포하지 않고 Noto Sans KR/OFL을 사용한다.
화면은 비율 확대 스크린샷이 아니라 실제 Compose UI로 구성하고 작은 기기/큰 글씨는 스크롤로 보호한다.
