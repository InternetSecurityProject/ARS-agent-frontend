# C 후보 선택 데이터 연결

사용자 승인 범위: 서버가 보낸 clarification 질문과 options를 기존 C 후보 버튼 톤으로 표시하고, 선택을 SessionAction.Select(requestId, key)로 전달할 준비만 한다. 기존 디자인, A 데모, 화면 미리보기, 앱 진입점은 유지한다. 실제 서버 호출은 하지 않는다.

## 접근

앞서 준비한 BServerCallScreen의 선택적 콜백으로 C를 확장한다. 데모 reducer를 서버용으로 변경하거나 별도 진입점을 추가하지 않는다. 화면은 HTTP/인증/세션을 소유하지 않는다. 소유자가 활성 연결 여부를 제공해야 선택 가능하다.

후보 순서·이름·키는 서버 값을 그대로 사용하고 confidence는 표시하지 않는다. 별표·우물정도 업무 선택지다. critical_action은 버튼만 제공한다. 빈 후보, 잘못된 기한, 만료, 중복 키는 선택을 막는다. 클릭 시에도 기한과 후보를 재검사한다.

요청당 선택은 한 번만 전달하고 서버 응답 전에는 다음 단계로 진행하지 않는다. 재시도는 자동으로 하지 않는다. 향후 연동 소유자는 명확히 미접수된 실패에 한해 retryVersion을 증가시켜 수동 재시도를 허용할 수 있다. 불확실한 실패에는 새 스냅샷으로 확인해야 한다.

## 제외

실제 API 호출, 앱 진입 연결, C 음성 답변·개인정보 키패드, 오디오, 새 아이콘, 프로토타입, 배포·푸시.
