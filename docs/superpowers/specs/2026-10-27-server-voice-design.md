# 서버 테스트: Agent 음성 대화와 ARS 듣기

사용자 승인: Android STT/TTS로 Agent와 음성 소통하고 ARS 소리 켜기/끄기를 연결한다. 상담원 통화와 실제 발신 검증은 제외한다. 추가 확인에서 기존 서버 테스트 화면·진입점·debug 권한 설정의 최소 연결 수정은 허용했다.

## 방식과 경계

선택된 방식은 앱에서 사용자 음성을 글자로 바꾸고 기존 goal/answer 계약으로 전달하며, 서버 질문과 핵심 진행 안내를 앱 TTS로 읽는 방식이다. 별도 음성 AI 서버 방식은 백엔드/API 변경이 필요하므로 채택하지 않는다. ARS 음성은 기존 audio_url의 수신 전용 WebSocket을 앱에서 재생한다.

- 기존 ServerTestController/Gateway/API 클라이언트, main 소스, 데모/갤러리와 백엔드는 수정하지 않는다. 별도 debug 음성 모듈을 추가하고 ServerTestActivity/ServerTestScreen/debug manifest에만 최소 연결한다.
- gateway를 장식하여 이미 생성된 세션을 음성 호스트에 전달한다. 추가 세션 생성이나 발신 경로를 만들지 않는다. 기존 확인창과 명시적 실제 발신 버튼 유지.
- 실제 배포 서버 호출·키 사용·실통화·커밋·푸시·병합은 하지 않는다. 기존 미커밋 작업은 보존한다.

## 사용자 동작

음성 안내는 사용자가 켜고 끌 수 있다. 목적은 ‘목적 말하기’에서 인식하여 기존 목적 입력칸에 채우고 발신은 자동 실행하지 않는다. 일반 clarification은 Agent가 질문을 읽은 뒤 답변을 듣고 확정 인식 결과를 기존 Respond(answer)에 한 번 전달한다. 재시도는 ‘말로 답하기’로 제공한다. 음성 입력 취소/무음/오류 시 자동 루프 없이 기존 글자 입력을 사용할 수 있다.

진행 안내는 상태 전환 때 핵심 문장만 읽으며 ARS 자막 전체/같은 snapshot을 반복 낭독하지 않는다. 빠르게 바뀌는 진행은 최신 안내를 우선한다. 새 질문은 이전 TTS/STT를 취소하며 완료 콜백도 현재 질문 ID·기한·종류·전송 가능 여부를 재검사한다. 같은 요청에 음성 답변을 중복 전송하지 않는다. 세션 교체/복원 시 이전 입력·콜백은 폐기한다.

critical_action은 버튼만, secure_input은 키패드만 유지한다. 이때 음성 인식을 시작하지 않고 안전한 일반 안내만 읽는다. 마이크는 Agent용 STT에만 사용하며 audio WebSocket으로 어떤 사용자 음성도 송신하지 않는다. 상담원 연결 상태에서는 ARS 재생과 음성 답변을 중단하고 미지원 안내만 표시한다. 서버 통화를 임의로 종료하지 않는다.

## ARS 수신과 음성 충돌

ARS 듣기는 명시적으로 켠 뒤 현재 세션에서만 연결한다. API origin·경로·스킴·세션 ID를 검증한 audio_url에 세션 token만 붙이고 redirect/재시도·앱 키 전송은 금지한다. G.711 μ-law 8kHz mono를 PCM16으로 디코딩하여 재생한다. 송신 기능 자체를 제공하지 않는다. 버퍼는 작게 제한하며 밀린 음성은 버리고 실패를 표시한다.

Agent TTS/STT 중에는 ARS 음성을 재생하지 않으며 지나간 소리는 쌓아두지 않는다. 끄기/종료/상담원 연결/백그라운드/화면 해제 시 소켓과 재생기를 정리한다. 백그라운드에서 마이크나 오디오를 유지하지 않으며 복귀 후 사용자가 다시 켠다. 오디오 오류는 기존 세션/발신 상태를 바꾸지 않는다.

## 권한·개인정보·실패

RECORD_AUDIO와 Android 11+ STT/TTS 서비스 검색 선언은 debug manifest에만 추가한다. 기본 데모는 새 권한을 요청하거나 음성을 초기화하지 않는다. 음성 인식 서비스가 외부 서버로 음성을 보낼 수 있음을 켜기 전에 알리고 마이크 권한을 요청한다. 한국어 STT/TTS 미지원/엔진 오류/권한 거절은 명시적으로 표시하고 텍스트·버튼·키패드 동작은 유지한다. 온디바이스 지원 시 우선하되 미지원 기기는 시스템 엔진의 정책을 따른다. 사용자 음성/키/토큰/개인정보를 파일·saved state·로그에 저장하지 않는다.

짧은 ARS 대기 시간은 앱만으로 늘릴 수 없고 인식 중에도 요청이 만료될 수 있다. 만료된 답변은 전송하지 않으며 후보 버튼을 항상 유지한다. 자유 발화 대화 모델·항상 켜진 연속 인식·배경 통화·상담원 통화는 이번 범위 밖이다.

## 검증

가상 음성 입출력으로 질문→TTS 완료→STT→단일 answer, 중복·기한·교체·critical/secure·백그라운드·실패를 JVM/Compose에서 검증한다. 로컬 MockWebServer로 수신 전용 바이너리 오디오, URL/토큰 경계, 끄기/종료 정리를 확인한다. 기존 전체 JVM/UI, 린트와 debug/release APK를 재검증한다. 실기기의 한국어 음질·인식 정확도와 배포 오디오 경로는 사용자의 후속 실제 테스트 항목이며 검증 완료로 주장하지 않는다.
