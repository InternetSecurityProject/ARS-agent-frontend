- 실화면은 Figma 기준이나 Android 시스템 영역과 Noto Sans KR로 플랫폼 차이가 있음. 팀 고정 키 서명은 Secrets 등록 후 별도 검증 필요.

## 독립 서버 테스트 모드 (2026-10-26)

- 사용자 승인: 기존 데모/화면 미리보기는 유지, 별도 서버 테스트 모드와 메모리 전용 API 키 입력. debug APK에 **ARS 서버 테스트** 아이콘 추가, release에는 포함하지 않음.
- 주소는 `https://ars.mcsmtp.org/v1`로 고정. 연결 확인은 키 없이 health만 읽으며, 명시적 테스트 시작 직전 sim/다른 활성 세션 여부를 재확인.
- 별도 컨트롤러에서 REST 생성·사용자 조작·결과, WSS snapshot/상태/안내/경로/입력/요약/종료를 연결. 기존 데모 타이머와 A/B/C/D 미리보기 코드는 변경하지 않음.
- API 키/토큰은 관찰 가능한 서버 상태/저장 상태/설정 파일/로그에 넣지 않음. 키와 민감 입력은 전송 시 입력칸에서 지움. Activity는 FLAG_SECURE로 화면 캡처 보호. 입력 기한·종류·중요 선택·실제 request_id를 확인하며 민감정보는 전용 조작으로 전송.
- 생성 응답 손실·HTTP 5xx/408은 처리 여부 불명으로 간주해 생성 재시작/입력 재전송 차단. 재연결은 snapshot 교체만 수행. 완료 REST 결과로 종료 이벤트 누락을 복구하고, 늦은 이벤트가 종료를 되돌리지 못하도록 스트림 중지·종료 상태 유지.
- 종료 실패 시 성공으로 표시하지 않음. 경고를 확인한 연결-only 닫기는 가능하지만 서버 세션은 남을 수 있음. 강제 종료/재실행 세션 복원과 실제 전화/음성은 이번 범위 밖.
- 최종 검증: JVM 77개·Android UI 33개(총 110개), 린트 오류 0/기존 경고 11개, debug/release APK 빌드 성공. 코드 리뷰 P2 두 항목을 세 회귀 테스트 RED→GREEN으로 수정.
