## 남은 작은 보완점

- 일반 통화 수동 키패드에도 Agent용 “10초 기다려요” 문구가 보임. 실제 대기 자동 재개는 Agent에만 적용되며, 문구 분기는 후속 작업.
- 번호 검증은 3~13자리 숫자와 010 분기만 적용. 완전한 국내/국제 전화번호 유효성, 실제 ARS 지원 판별은 별도 계약 필요.
- 실제 전화/STT/DTMF/상담원 연결 완료는 이번 UI 데모 밖의 범위. immutable 문자열의 메모리 완전 삭제를 보장하지 않으며, 상태 비우기와 비저장만 적용.
- 실화면은 Figma 기준이나 Android 시스템 영역과 Noto Sans KR로 플랫폼 차이가 있음. 팀 고정 키 서명은 Secrets 등록 후 별도 검증 필요.

## API 통신 기반 추가 (2026-10-25)

- 사용자 승인 범위: 통신 기반·로컬 모의 서버 테스트만. 기존 데모와 A/B/C/D 미리보기는 유지.
- `data/api`: API v0.3 직렬화 모델, REST 세션 생성/6종 조작/결과/health, 이벤트 WebSocket과 안전한 오류 구분.
- REST/WS 주소·앱 키를 명시적으로 전달하는 설정. 앱 실행 시 네트워크 요청 없음. INTERNET 권한은 준비했지만 클라이언트는 UI에 연결하지 않음.
- HTTPS/WSS 기본, debug 로컬 HTTP만 제한적으로 허용. 토큰의 외부 origin 전송·redirect·발신/조작 자동 재시도를 차단.
- snapshot/입력 요청/선택지/경로/요약을 구조화. 이벤트 재구독은 새 snapshot을 받으며, 사용자 입력은 자동 재전송하지 않음.
- 실제 서버/발신 서비스는 호출하지 않았으며 배포 주소 검증, UI 상태 매핑, 실제 오디오/STT는 후속 작업.
- 자세한 설정·예제·보안 경계·미확정 계약: `docs/api-integration.md`.
- 최종 검증: JVM 48개(신규 통신 30개 포함), Android UI 16개 통과. `lintDebug` 오류 0, debug APK 빌드 성공. SDK/의존성 업데이트 및 기존 백업 설정 권고 경고는 남아 있으며 이번에 버전 업그레이드는 하지 않음.
- 독립 리뷰 후 `503 Retry-After:0`의 POST 재전송을 one-shot body로 차단하고, 종료 snapshot의 Flow 완료 및 실제 서버의 nullable `input_rejected.keys` 처리를 RED→GREEN으로 검증.
